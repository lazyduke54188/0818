# Vocab Coach AI

Vocab Coach AI is an interactive, web-based English vocabulary learning assistant powered by Google Gemini AI (`gemini-3.6-flash`).

## Features

- 🤖 **Gemini AI Integration**: Uses `gemini-3.6-flash` model for intelligent, contextual vocabulary teaching.
- 📖 **Structured 3-Part Learning**: Presents target vocabulary with clear explanations and example sentences.
- 🔊 **Text-to-Speech (TTS)**: Built-in pronunciation audio using browser Web Speech Synthesis.
- 💾 **Session Management**: Save and reload learning sessions locally in browser `localStorage`.
- ⚙️ **Customizable System Prompt**: Easily adjust coach settings and persona.

## Getting Started

1. Open `vocab-coach.html` in any web browser.
2. Enter your Gemini API key in the top bar.
3. Click **Start the first lesson** to begin learning!
